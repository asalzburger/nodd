# DES-007 short-strip ring study — PROTOTYPE

An isolated analytical screen for [DES-007](../../docs/design/DES-007-short-strip-modules.md).
It does not build or configure a detector. All proposed hardware remains unsigned.
Dependencies: Python 3, NumPy; Matplotlib only for the optional figure. Existing
local versions used for retained results are recorded in the JSON; no packages
were installed by this task.

From the repository root:

```sh
python3 -B -m unittest discover -s tools/short_strip -p 'test_*.py' -v
MPLCONFIGDIR=/tmp/nodd-mpl-short-strip python3 -B tools/short_strip/study.py --refined --figure docs/design/figures/DES-007-rings.svg
python3 -B tools/short_strip/study.py --input tools/short_strip/inputs-initial.json --refined --output docs/validation/DES-007-ring-study-initial.json
```

To reproduce without overwriting retained evidence, use `--output /tmp/results.json`
and `--figure /tmp/rings.svg`. Git revision/working-tree metadata will differ;
compare `configuration` and `results` for deterministic numerical reproduction.
`inputs-initial.json` preserves the failed 2 mm edge-margin experiment;
`inputs.json` uses the physically motivated 4 mm margin. The Markdown report is
curated from these outputs, not generated by the script. Never silently update
reviewed results after changing the model.

Units are mm. Each active sensor is a convex polygon in global xy at its nominal
ring position. Rectangular sensors are exactly congruent within each candidate.
Custom wedge rings have one shape per ring. Width fixes an approximate module
scale; even azimuthal counts allow alternating z levels. The conservative body
is the active polygon's local bounding rectangle plus guard and service space.
Adjacent rings and modules occupy four levels. A separating-axis check rejects
same-level interior body intersections; level separation exceeds trial thickness.
This checks only fixture bodies, not a real cooling/support assembly.

Coverage uses 500 radial × 1440 azimuthal midpoints, and `--refined` repeats at
1000 × 2880. Weights proportional to radius give polar-bin area weights.
The nearest module and two neighbours in each ring are tested using half spaces;
tests verify that the angular support is inside that search window and compare
against a brute-force loop over all globally transformed modules. Straight rays
from vertex z = −150, 0, +150 mm intersect the stagger levels of the 1320 mm disk.
The reported missing area is relative to the target annulus in the nominal disk
plane. Polygon boundaries use a 1e-9 mm² cross-product numerical epsilon, not an
engineering clearance tolerance. SAT uses a corresponding projection epsilon.
The same-level collision result excludes boundary touching; touching would need
an explicit clearance check in the later engineered module.

Outputs include counts, actual polygon vertices, trial envelopes, sensor-area
ratios, channel-area estimates, projected multiple crossings and coverage. The
area ratio includes both overlapping silicon and silicon beyond the target
annulus; it is not an overlap fraction. Partial wedge cells and non-integer
long-cell rows require real layout work. Coverage is sampled, not proven, and
omits curvature, material, dead ASIC seams, inefficiency and alignment errors.
Source hashes and provenance live in the manifest and DES-007; script/input
hashes, environment and source revision live in each numerical result.
