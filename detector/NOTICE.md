# Provenance notice

`config/elements.json` contains numerical element definitions extracted from
`xml/OpenDataDetectorElements.xml` in the public OpenDataDetector repository,
revision `c167363f3d4ad1540a577af99071283caf54f3a6`. Original file SHA-256 and
source identification are retained in that JSON. Upstream license: MPL-2.0,
reproduced in [config/ELEMENTS-LICENSE](config/ELEMENTS-LICENSE).

The component/factory implementation is newly written nODD code. The public ODD
material recipes cited by DES-012 are provisional comparators; this is not a
copy of the ODD detector. Numerical element data do not approve detector material
choices. The complete table supports ROOT's elemental lookup; sparse registration
is insufficient for its mass-fraction material converter.
