## Recovery and provenance

The repository recovery tool reads selected-project thread/turn metadata and
decodes only token-count events. Each cumulative request increase equals the
reported last-request increment; repeated snapshots are excluded. Persisted
boundaries, request counts and SHA-256 usage-event hashes are retained in
[the curated synchronization inventory](USAGE-2026-10-07-synchronization.json).
Only selected exposed user-visible task requests were used for attribution;
no raw conversation or private model state is retained.

The curated ACTS validation receipts are copied byte-for-byte into
`logs/evidence/acts-nodd-examples` from nODD revision
`97439b801a92c79b13325a91365b6deff309fb29`, retaining the original native/source/output
hashes. A magnetic-research plan link targets its original branch revision
instead of importing that separate scientific deliverable. These corrections
repair actual broken log links without claiming a new run.
