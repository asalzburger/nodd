## User interactions

The complete available histories of the two main project chats contain **56 user chat messages across 51 user-initiated turns**: 34 messages/31 turns in “Review PR #133 question”, and 22 messages/20 turns in the LAr cross-check chat. Five messages are steering or clarification/approval replies inside an existing turn. Interrupted requests are included. Two automatic continuation turns without a user message are excluded from the user-turn count.

There are separately **three public GitHub request inputs**: issue131, the PR133 output-size question, and the PR145 review instruction. The issue131 agent-task launch is one automated invocation implementing the issue, not an additional human request. Thus the inspected evidence contains **59 distinct human input actions** when chat messages and public requests are combined. The connected histories, exact message/turn IDs and selected user text are retained in the JSON companion; missing/deleted/other-device conversations cannot be ruled out.

Do not use the 658 ledger event rows as a user-interaction count. They contain assistant progress messages, agent-to-agent assignments and repeated journal/curated representations of the same input. Template text was also retained as a prompt in two historical journal entries; it is excluded here. Approval reviews are recorded reactions, not additional user requests.

## Reproduction and evidence

[Machine-readable audit](AUDIT-2026-11-19-pr133-151.json) contains the canonical account references/counters, four supplemental usage digests, 56 selected user inputs, and per-job source paths, compact receipt hashes, event requests, exit codes and observed wall/CPU time. Run receipt hashes cover canonical JSON (`sort_keys=True`, separators `(',', ':')`). Full commands, raw simulation/event files and raw client archives are not copied into this audit.

To reproduce the headline sums, deduplicate all `tokens.accounts[].usage` and `tokens.supplemental_closed_turns[].usage` by thread/turn pair, sum input/output, and require input+output=total. For jobs, group `simulations.runs` by `kind` and exit code; sum event requests only for successful transport records. Missing durations remain null. Public metadata and affected interaction references were refreshed; final gate results are in the paired [audit session](../codex/SESSION-2026-11-19-pr133-151-accounting.md).
