# (Human) Review Instructions 

## Asignment 

The project owner (@asalzburger) or the final sign-off responsible (@asalzburger-review) may request review from you on certain PRs.
Passing a review is necessary to move to the next planning or implementation stage, but is not binding. 

The main objectives of the review are:
 - give an interface for human-agent interaction that is traced
 - allow shaping the research with input from several sides
 - eventually record (sign-off) decisions

## Review roles

- `asalzburger` - this is the single comitter representing the agentic system 
- `asalzburger-review` - human reviewer (Andreas Salzburger), final signoff
- various experts (including you probably)

## Review procedure

The PR summary should guide through the topic of the PR, if this is not happening, comment on it, ask for a clearer PR description.
The comments will be picked up by the agentic system and will be answered and processed, leading eventually to changes of the PR description and content.

If several reviewers ask different/orthogonal questions, or the agentic system does follow the reasoning, it will ping `asalzburger-review` for adivce on how to proceed.

Treat the PR as the communication panel to the agentic system, both general comments in the `Conversation` tab or comments on individual files can be done, the agentic system will read all of those in the next cycle.
