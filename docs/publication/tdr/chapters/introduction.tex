\chapter{Introduction}
\label{ch:introduction}
nODD develops an experiment-independent reference detector with explicit module,
support, cooling and service hypotheses. The preliminary pixel baseline combines
an unchanged barrel with radially oriented single- and quad-module endcaps.
The selected endcap layout removes only complete inner rings proved inaccessible
within the stated track and luminous-region envelope.

This manuscript records a preliminary design and an isolated DD4hep implementation.
Selection by the project maintainer establishes the comparison baseline; it does
not establish manufacturing readiness, engineering sign-off or full-detector
acceptance. Detector parameters, derivations and validation evidence remain
canonical in the nODD Git repository. The sources and generated assets in this
review copy are self-contained for pdfLaTeX and can be transferred to Overleaf
by a deliberate manual publication step.

\Cref{ch:pixel} describes the selected layout, local support and services,
implementation and measured construction checks. Other detector systems and
performance chapters remain outside this update.
