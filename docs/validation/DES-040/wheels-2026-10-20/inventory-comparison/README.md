# Before/after chamber shape inventory

[Before endcap](before-endcap.md) · [After endcap](after-endcap.md) · [Current repacked barrel](current-barrel.md). Endcap shape sheets use identical metric limits, including the long whole-wheel trapezoids. All shapes use the same blue diffuse colour as the OBJ.

Before: 1560 chambers. After: 1344 chambers. The [comparison JSON](comparison.json) gives counts by station/hemisphere and every panel's intrinsic dimensions and ID status; [mapping CSV](shape-change-mapping.csv), before/after-panels-unrounded.csv retain the source identities and unrounded dimensions. Shape-family display grouping uses 1 nm dimensions; it is not a manufacturing tolerance. A new whole wheel is not paired artificially one-to-one with removed ordinary modules.

This is source geometry bookkeeping, not reconstructed efficiency, MDT manufacturing or engineering acceptance. [Provenance](provenance.json). Reproduce with the wheels_artifacts command in ../obj-revised/README.md.
