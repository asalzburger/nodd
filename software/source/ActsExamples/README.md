# Local ActsExamples extensions

nODD-specific algorithms, detector adapters and external interfaces belong here.
Use ACTS's Sequencer, whiteboard and algorithm interfaces. Do not edit the ACTS
submodule to add local algorithms.

The isolated [Gen3 portal material prototype](MaterialMapping/README.md) adds
keyed proto materials and a Geant4 step-midpoint adapter for ACTS material
mapping. It builds as a sidecar against an explicitly supplied ACTS installation.
