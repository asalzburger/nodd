## Role and limits

Use this paper for the original detector's overall arrangement, subsystem roles,
magnet interfaces, supports and services. Read later subsystem TDRs alongside it
with explicit dates. This 2008 configuration predates the RD53-based upgrades;
it is not a specification for those upgrades or for nODD.

The aim is realistic component usage for simulation. Extract geometry envelopes,
active/passive structure, segmentation, material and service relationships when
needed. Manufacturing detail is optional unless it affects the preserved physical
quantities. No parameter is adopted here and no DD4hep code is generated.
